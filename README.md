# 页知译 · 网页双语翻译

Chrome Manifest V3 网页双语翻译扩展，保留原文并展示译文。
代码版本以 [manifest.json](manifest.json) 为准，版本变更见 [CHANGELOG.md](CHANGELOG.md)。

## 功能

- 支持 Google、MyMemory、百度及 OpenAI 兼容 AI 服务，可连接本机 Ollama 和自定义接口。
- 双语对照、仅译文、选中文字翻译，以及鼠标所在段落的 Shift 翻译与还原。
- 可自定义译文字体、字号比例、颜色、字重、正文行高及段落间距，支持实时预览与恢复默认。
- 识别正文、侧栏、网页弹框和控件旁说明；正文中的链接与行内代码按同一翻译单元处理。
- 译文独立插入，不包装或搬动网页原节点；动态更新时清理失效译文，取消后保留网站新内容。带图标的网格与横向布局按正文区域安排译文。
- 优先翻译可见区域；当前页启动后持续补翻，点击取消后恢复原文并暂停本页补翻。
- 请求去重、有限内存缓存、按服务限流、有限重试；离开标签页暂停新发送，返回后继续。
- 开放式 Shadow DOM 组件内文字参与整页、Shift 和动态补翻，保留组件原节点与交互。
- 技术术语表：内置保留 Linux、RHCE、OpenShift 等原名，自定义固定译法、按语言启用及 JSON 导入导出；网页、PDF、OCR 共用。
- iframe 内嵌网页随主页面开始/取消翻译，覆盖同源、允许访问的跨源和相关空白文档；只显示一个控制面板。鼠标放在框架内的文字上按 Shift 可翻译/还原，无需先点击框架。
- 图片在本机 OCR，支持印刷体英文、简体中文，先校对再翻译。
- 在线/本地文字型 PDF 双语阅读：支持左右对照和原版式译文切换；按页解析和翻译。
- 提供 48 种语言选项，默认自动检测源语言、目标语言跟随浏览器，也允许手动覆盖。

## 安装与使用

1. 下载或克隆仓库，打开 `chrome://extensions` 并开启开发者模式。
2. 选择“加载已解压的扩展程序”，加载包含 `manifest.json` 的项目根目录。
3. 在扩展设置中选择翻译服务；百度和多数 AI 服务需自行配置凭据，自定义域名需主动授权。
4. 点击悬浮球开始/取消整页翻译。默认快捷键为 Ctrl+Shift+Y，Mac 为 Command+Shift+Y。
5. 启用单段翻译后，把鼠标停在段落上按 Shift：有译文则还原，没有译文则翻译。
6. 修改代码后重新加载扩展并刷新网页。

### PDF 双语阅读

- 在线 PDF：打开 PDF 后点击扩展图标；无 `.pdf` 后缀的地址，也可右键选择“用页知译打开 PDF 双语阅读”。
- 也可从网页控制面板或扩展设置中的“PDF 双语阅读”入口打开阅读页，填写在线地址或选择本地 PDF。
- 在线读取时按来源网站申请权限，文件在浏览器本地解析；最大 50 MB，不会整份上传。需要登录、链接无法读取时，可下载后选择本地文件。
- 点击“开始翻译”后，当前页文字发送到所选服务；处理中显示加载图标和“正在翻译…”。全部完成或部分失败后显示“重新翻译”，点击会重译本页全部段落并刷新对应缓存；状态栏另行说明失败数量。翻页后自动续翻仍可复用缓存。
- 点击“取消翻译”恢复原文并停止续翻，同时仅在阅读页内存暂存当前页已完成结果；按钮显示“继续翻译”，点击恢复已有译文，只处理未完成或失败的段落。翻页、换文件或更改服务、语种、凭据及术语表后旧进度失效；关闭阅读页不保存进度。
- 左右对照显示两张相同版式的页面：左侧原 PDF，右侧在原位置显示译文，保留分栏、表格线、流程图节点、箭头、图片和背景；两侧同步滚动。识别出的作者、联系方式和代码保留原文，不发送翻译。
- 译文页沿用原 PDF 的图形绘制，只隐藏已成功翻译且可靠匹配的原文字形；译文文字层背景透明，不用整块填色遮盖图形。字体与断行会根据译文长度调整，不能保证任意 PDF 都完全还原。
- 译文以段落主要文字字号为基准，上标、商标等小字符不再缩小整段；为保持可读性，适配时最多缩小约四分之一，仍放不下时点击查看全文。分批返回的结果只更新变化的文字，已有译文不反复重建，新文字完成字号适配后显示。
- 在“阅读方式”中切换“左右对照 / 原版式译文”，后者单独显示译文整页；切换复用已有译文，不重复请求。单页模式提供“译文页查看原文”开关和排版说明；左右对照已有左侧原文，因此隐藏这两项，只保留不能安全替换、绘制失败等特殊提示。点击译文可查看原文与完整译文；过长译文显示虚线框，不扩大区域挤乱周边图形。
- 不能安全匹配的文字、旋转/竖排、特殊字体或参与裁切的文字保留原绘制；失败段落同样保留原文，可展开页面下方“文字译文与失败详情”查看。文字详情按标题、正文、图注、代码和可识别表格整理，默认收起。原始文件不会改写，当前不生成译文 PDF。
- PDF 阅读页仅翻译可提取的文字；不提供扫描图片文字识别、密码解锁或译文 PDF 导出。无文字的扫描页仍可阅读，并显示不能提取文字的提示。

### 图片识别与术语表

- 独立图片页：点击悬浮球或扩展图标，进入图片翻译页并带入来源；不带图片后缀的链接按文档类型识别。申请来源权限成功后自动预览，再手动识别和翻译。
- 网页内图片：右键网页图片选择“页知译 · 识别并翻译图片文字”，或从扩展图标右键菜单、设置页进入。读取在线地址需主动授权，已授权入口自动预览；本地图片可选择或粘贴，最大 20 MB，画布最多约八百万像素。
- “识别图片文字”与“翻译文字”相邻排列；先点击识别、校对右侧文字，再点击翻译；识别、校对不会主动发起翻译请求。识别语言支持英文和简体中文 + 英文，扫描模糊、手写及多栏内容可能识别错误，请先校对。
- Tesseract.js 7.0.0、WASM 和中英文语言数据随包附带，新增约 49.6 MB；不依赖 CDN，识别后释放 Worker，不持久保存识别文件或结果。
- 设置页“技术术语表”可添加原词和固定译法，译法留空保留原词；长词优先，具体语言规则优先于“所有语言”，自定义规则覆盖内置。最多 500 条，自定义表保存在本机，导入 JSON 后需点击保存。
- 从链接跳转后使用浏览器后退/前进，恢复活动文档身份并重新建立请求批次；保留已有译文和用户暂停状态。在其他页面修改了翻译配置时，返回后按新配置清理旧结果。
- 保存术语表会清理旧译文，已启动的网页按新规则补翻；PDF 和图片请重新点击翻译。若服务损坏术语保护标记，会提示失败，不插入缺损译文。
- iframe 仍受 Chrome 网站访问设置、沙箱和浏览器限制约束；封闭式组件、跨源播放器中的画面或音频不属于网页文字翻译，视频功能留待后续版本。

新安装默认关闭自动翻译。翻译文字会发送给所选服务；API 凭据和请求配置仅存本机，普通偏好可经 Chrome 同步。
扩展使用 `webNavigation` 核验前进/后退恢复的活动文档，不保存或上传浏览历史。
详见 [隐私说明](PRIVACY.md) 和 [公开隐私网页](docs/privacy.html)。

```text

├── core/           共享配置、语言、翻译单元、请求策略和调度运行时
├── settings/       扩展设置页
├── pdf/            PDF 阅读页及随包附带的 PDF.js、字体与许可证

├── tests/          逻辑与浏览器回归测试，随代码提交

├── .github/        GitHub Actions 自动检查
├── docs/           公开隐私网页，保留既有访问路径
├── .local/         本地手册、填写草稿、商店图片与原型，不提交
├── dist/           本地安装包及验收副本，不提交
├── node_modules/   本地开发依赖，不提交
├── manifest.json   扩展入口、权限、资源与版本声明
```

运行目录保留在根目录，使 Manifest 引用与“加载已解压扩展”的路径清晰稳定。
依赖、生成物、编辑器个人配置及 `.local/` 均由 `.gitignore` 排除；Git 克隆不会带上个人资料。

## 开发与检查

GitHub Actions 使用 Node.js 22；本地推荐使用同一主版本。首次安装或锁文件更新后：

```powershell
npm ci
npx playwright install chromium
```

| 命令 | 用途 |
| --- | --- |
| `npm run check` | 源码语法、Manifest 引用、版本一致性 |
| `npm test` | 日志、采集、存储、权限、语言及调度逻辑回归 |
| `npm run test:browser` | Chromium 布局、动态网页、单段与完整扩展集成测试 |
| `npm run package` | Windows 下生成运行白名单 ZIP，不覆盖同名旧包 |
| `npm run store:assets` | 手动导出本地商店图片、截图与运行图标 |

测试使用独立浏览器资料和模拟服务。真实账号、额度、网络与第三方网页仍需人工验证。
长期开发基准为 `dev`，稳定基准为 `main`；具体任务从 `dev` 创建临时分支，完成后集成测试，再按交付范围合入 `main`。

## 日志与打包

日志在 `core/constants.js` 的 `LOG_CONFIG` 配置：环境为 `development` 时允许按 `off/error/warn/info/debug` 级别打印。
修改后重新加载扩展并刷新网页；详细诊断需在浏览器控制台启用 Verbose/详细级别。
日志不得包含原文、译文、密钥或完整请求对象。

Chrome 商店草稿上传由 `.github/workflows/chrome-store-upload.yml` 执行：推送与版本一致的 `v*` 标签后，校验其提交已进入 `main`，自动测试、打包并上传现有商店条目；也支持从 `main` 手动选择标签运行，并可关闭“运行自动化测试”仅试传草稿。仓库 Actions Secrets 需要配置 `CWS_SERVICE_ACCOUNT_JSON`、`CWS_PUBLISHER_ID` 和 `CWS_EXTENSION_ID`。此流程仅上传草稿，审核由开发者在商店后台手动提交。

明确准备发布时才执行 `npm run package`。输出为 `dist/yezhiyi-translator-<Manifest版本>.zip`，仅包含运行文件、图标与隐私说明。
脚本在临时发布副本中强制关闭插件主动日志并检查 ZIP，不改本地开发配置；手动压缩源码不会执行此转换。
普通分支推送和 GitHub Release 不触发商店上传；版本标签仅触发草稿上传，上线仍需在商店后台手动提交审核。

个人操作手册、发布填写草稿、商店图片和原型集中保留在本地 `.local/`；本地入口为 `.local/README.md`。
这些资料不属于运行代码，不会提交到 GitHub 或进入安装包。

## 已知边界

- 不支持封闭式 Shadow DOM、浏览器内置页面和原生系统弹框；iframe 受 Chrome 网站访问与沙箱限制，视频画面和音频不属于网页文字采集。PDF 和图片通过独立阅读页处理。
- 不翻译输入框已填内容、密码、placeholder 或原生下拉选项；代码与明确禁译内容按采集规则处理。
- 语言选项不是接口实时返回的完整语种列表，实际支持取决于所选服务或模型。
- MyMemory 对部分短文字无法可靠识别源语言，需要手动指定或切换服务。
- 网络可用性、限流、计费和数据处理规则由所选服务决定；取消不能撤回服务端已收到的内容。
- 当前未添加开源许可证。

PDF 阅读页使用 Mozilla PDF.js 6.4.299，按 Apache-2.0 随附，来源和许可证见 `pdf/vendor/SOURCE.md`、`pdf/vendor/LICENSE` 及资源目录内说明；这不改变本项目自身的许可证状态。OCR 依赖来源、固定版本及许可证见 `ocr/vendor/README.md`。
