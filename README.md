# 页知译 · 网页双语翻译

当前代码版本：**1.0.0**。Chrome Manifest V3 网页双语翻译扩展。已完成本地自动化验证，尚待真实服务人工验收和 Chrome 网上应用店审核。

## 功能

- Google、MyMemory、百度及 OpenAI 兼容 AI 服务，支持本机 Ollama 和自定义接口。
- 双语、仅译文、划词和悬停翻译；识别段落、侧栏、混合表单文字、图标按钮和网页弹框。
- 可见区域优先，动态内容局部补翻；取消后还原原文并暂停当前页面。
- 自定义接口授权、语言代码映射、重复请求合并、有限内存缓存、请求限流与失败冷却。
- 密钥和服务配置仅存本机，普通偏好可经 Chrome 同步。

## 语言范围

源语言和目标语言共用 48 种语言目录，源语言另有自动检测。包含中、英、日、韩、法、德、西、俄，以及意大利语、葡萄牙语、阿拉伯语、泰语、越南语、印尼语、土耳其语等。目录与服务代码统一维护于 core/constants.js；实际翻译质量和可用语种仍受所选服务或模型限制，并非运行时获取服务的完整语言列表。

## 安装与使用

1. 下载或克隆仓库。
2. 打开 chrome://extensions，开启开发者模式，加载包含 manifest.json 的文件夹。
3. 点击扩展图标，进入设置并配置翻译服务。自定义接口请点击测试或启用并允许对应地址访问。
4. 点击悬浮球翻译当前页；再次点击取消。默认快捷键是 Ctrl+Shift+Y，Mac 为 Command+Shift+Y，可在 Chrome 的扩展快捷键页面调整。
5. 更新代码后重新加载扩展并刷新网页。

新安装默认关闭自动翻译，需要时自行开启；已有偏好保持。翻译文字会发给所选服务，使用前请阅读 [隐私说明](PRIVACY.md)。

Windows 下执行：

~~~sh

~~~

输出 dist/yezhiyi-translator-1.0.0.zip，只包含 Manifest、运行代码、图标与隐私说明，不包含测试、依赖、Git 元数据和本机配置。发布前先完成上方验证。为避免覆盖旧包，输出已存在时脚本会停止。

## 已知边界

- 暂不覆盖 iframe、Shadow DOM、图片文字、浏览器原生 alert/confirm/prompt。
- 输入值、密码、placeholder 和原生下拉选项不翻译。
- 自动检测目标为中文时会跳过中文内容；需要简繁转换时明确设置中文源语言和另一种中文目标语言。
- MyMemory 自动源语言使用浏览器本地检测，不可靠时提示手动指定；其余接口按所选服务规则处理。
- 请求重试最多三次，仅在后续页面事件发生且冷却结束后重试；手动重试可以恢复。取消会移除本页排队任务，并尝试中止未被其他页面共享的网络请求；服务端已接收的内容仍可能被处理或计费。
- 长页面性能数字仅代表构造测试，不保证所有网站都有同样表现。
- 当前未添加开源许可证。

## 版本

以 manifest.json 为版本来源，设置页自动读取；package.json 与测试检查版本一致性。变更见 [CHANGELOG.md](CHANGELOG.md)。

默认源语言为自动检测，目标语言跟随浏览器界面语言；可在设置页或页面面板手动覆盖，也可重新选择“跟随浏览器”。已有手动语言配置保留。浏览器语言不在支持列表时回退为英语。

运行日志默认关闭。如需排查翻译进度，可将 core/constants.js 中的 DEBUG 改为 true，重新加载扩展并刷新网页。翻译失败原因仍在页面面板显示，配置同步异常保留控制台警告。调试完成后请恢复为 false。

发布材料与商店填写说明见 [商店上架准备](docs/STORE-LISTING.md)。远程自定义接口仅接受 HTTPS，本机 localhost / 127.0.0.1 可使用 HTTP。局部自动补翻保留已完成的界面状态，不反复切换按钮与徽标。
