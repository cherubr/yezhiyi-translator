技术术语表

为网页翻译统一译法；术语只保存在本机。

使用说明
保留原词
译法留空时保留原文，例如 RHCE 仍显示为 RHCE。
优先匹配完整术语
同时设置 OpenShift 和 OpenShift Container Platform 时，遇到完整名称会优先按较长的术语处理。
相同术语使用你的设置
内置规则保留 Red Hat 原名；添加“Red Hat → 红帽”后，在规则指定的目标语言下使用“红帽”。
目标语言决定规则何时生效
“所有语言”表示无论翻译成哪种语言，都使用这条规则。RHCE 保留原名适合选“所有语言”；“kernel → 内核”建议选“简体中文”，避免在翻译成其他语言时也显示“内核”。
导出用于备份或迁移
导出 JSON 会保存当前编辑的术语和开关设置，也包含尚未点击保存的修改。
导入后需要保存
导入 JSON 会替换当前编辑内容；点击“保存术语表”后才生效。需要保留现有内容时，请先导出。

隐私与数据

翻译时，所选文字会发送给您选择的翻译服务；自动翻译默认关闭，开启后会自动发送可翻译的可见文字。密码、输入值和可编辑区域不参与整页翻译。

密钥和接口配置保存在本机；普通偏好可能经 Chrome 同步。译文缓存仅驻留内存，最多保留十分钟。不包含统计或广告代码。自定义服务接收的数据受其自身规则约束。

使用说明

  • 点击悬浮球：翻译 / 取消翻译当前页面
  • 悬停悬浮球：出现小图标，点击打开控制面板
  • Shift + 悬停段落：翻译 / 还原该段
  • Ctrl + Shift + Y（Mac：Command + Shift + Y）：翻译 / 取消翻译当前页面
  • 右键菜单：翻译整页 / 翻译选中文字
