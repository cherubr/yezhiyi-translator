页知译 · 隐私与数据说明

更新日期：2026 年 11 月 2 日

本说明适用于“页知译 · 网页双语翻译”Chrome 扩展，说明网页翻译、PDF 阅读和图片文字识别如何处理数据。可用功能以您安装的版本为准。

翻译文字直接发送给您选择的服务。PDF 解析和图片 OCR 在本机完成，扩展不会将原始 PDF 或图片上传给翻译或 OCR 服务。API 凭据仅保存于本机，部分普通偏好可通过 Chrome 同步。

一、文字与文件如何处理

网页文字

  • 手动整页、划词、Shift 单段或普通悬停翻译时，需要翻译的文字、源语言、目标语言和服务所需参数会发送给所选翻译接口。使用 AI 服务时，还包括模型名称和翻译指令；凭据按所选接口的认证方式使用。
  • 新安装默认关闭自动翻译，旧用户保存的偏好不被强制覆盖。开启自动翻译或主动开始当前页翻译后，符合采集规则的可见内容会发送；滚动、弹框或动态更新可能触发补翻。
  • 默认单段翻译要求主动按 Shift；若改为无需按键的普通悬停模式，鼠标停留也可能触发文字发送。
  • 自动和整页采集跳过输入值、密码、textarea、select、可编辑区、代码区、不可见及明确禁译区域。主动 Shift 可覆盖网页的 translate="no" 等禁译标记，仍跳过输入值、编辑区和代码。
  • 开放式 Shadow DOM 与允许访问的 iframe 使用相同采集规则；主页面开始或取消会同步控制子框架。扩展不读取封闭式 Shadow DOM 内部内容。
  • 扩展不主动把当前网页地址、浏览历史或整页 HTML 加入翻译请求，但正文自身可能包含网址、姓名或其他私人信息。请按需选择文字，避免发送不希望交给服务方的内容。

PDF 阅读与翻译

本地文件通过选择器读取，在线 PDF 由您主动读取并授权来源网站，文件在浏览器本机解析。扩展不改写原文件，也不将原始文件、文件名、来源地址或文档元数据主动加入翻译请求。

点击“开始翻译”后，当前页提取且需要翻译的文字发送给所选服务；翻页后可自动续翻。识别为代码、作者或联系方式的文字块保留原文，但结构识别依赖字体与坐标，不能保证排除所有个人信息。PDF 阅读页不提供扫描图片 OCR。

“重新翻译”会重新处理本页需翻译文字。取消后恢复原文、停止续翻，并仅在阅读页内存暂存本页成功结果；点击“继续翻译”恢复已有结果并处理剩余段落。翻页、换文件或更改翻译配置会丢弃旧进度，关闭阅读页不保存进度。原文件及页面数据可能在阅读期间保留于页面内存，不写入扩展持久存储。

图片识别与翻译

图片可通过主动读取在线地址、选择文件或粘贴提供。OCR 引擎在本机识别英文、简体中文，原图不发送给 OCR 服务器。读取、预览或识别图片不会自动翻译；只有点击“翻译文字”后，当前编辑框中需翻译的文字才发送给所选服务。

图片、画布及识别结果不写入扩展持久存储，关闭页面后不保留；OCR 完成或取消后释放识别 Worker。PDF.js、字体、解码器、OCR 引擎与语言数据均随扩展附带，不从第三方 CDN 加载运行代码。

连接测试与术语保护

主动点击“测试连接”会向对应接口发送固定测试文字及必要认证信息，以验证连接。自定义术语表在本机应用，不主动发送整张表；匹配的固定译法在本地还原，受保护内容用内部标记参与请求。

二、哪些服务会接收数据

  • 翻译服务：Google、MyMemory、百度、您选择的 AI 厂商或填写的自定义接口直接接收翻译请求；扩展没有自建翻译中转服务器。服务方的数据保留、模型训练、收费和其他处理规则由其决定，请查阅所用服务的政策。网络连接也会向接收方暴露 IP 地址等通常的连接信息。
  • 本机模型：Ollama 的文字发送至您配置的地址；使用本机回环地址时请求留在本机，远程部署则发送到对应服务器。远程接口只允许 HTTPS，HTTP 仅允许 localhost 和 127.0.0.1。
  • 文件来源网站：在线 PDF 和图片读取会直接连接来源网站，可能携带浏览器允许的该网站登录 Cookie。重定向可能需要额外来源权限；无法读取时可下载后手动选择文件。
  • Chrome 同步：普通偏好可能经您的 Chrome 账号同步，详见下节。扩展不将 API 凭据或术语表写入同步区。

扩展不包含广告、使用行为统计或自建数据采集服务器。本隐私网页由 GitHub Pages 托管，访问网页本身会连接 GitHub 的托管服务；页面不加载统计脚本、远程字体或外部运行代码。

三、本机保存与 Chrome 同步

仅保存在本机的配置
API 密钥、AI 接口地址和模型、百度 AppID 与密钥及验证记录、请求频率与并发策略、自定义术语表保存在 chrome.storage.local。术语表可主动导出为 JSON。本机存储不等同于加密保险箱。
可能通过 Chrome 同步的偏好
所选服务、语言、显示模式、译文样式、自动翻译与悬停开关、快捷键偏好和悬浮球位置等保存在 chrome.storage.sync，可能同步到您使用同一 Chrome 账号的设备。
旧版凭据迁移
旧版同步凭据首次读取时迁移到本机，成功写入后清理旧同步字段；本机已有配置优先。扩展不能直接控制同步服务保留的历史副本。
临时文字与结果
为合并请求、限流和减少重复调用，原文、译文及配置索引暂存于后台内存。缓存最多 256 条，成功结果有效期十分钟，失败信息冷却三十秒；扩展不将缓存写入持久存储，后台线程退出后清空。网页、PDF 和图片阅读期间的显示结果还可能保留在各自页面内存中。

四、浏览器权限用途

  • 网页与接口访问：在 Chrome 允许的网站注入采集与译文界面，并调用所选翻译接口。自定义接口在主动测试或启用时按地址申请权限。
  • 可选文件来源访问：在线 PDF 和图片的来源权限独立于翻译接口权限，仅在主动读取或图片入口操作中申请。授权后的图片入口可自动预览原图，不自动识别或翻译。
  • storage：保存本机配置与可同步偏好。
  • contextMenus：提供翻译、PDF 阅读及图片识别等右键入口。
  • tabs：定位当前标签页、发送翻译控制消息，以及打开或复用扩展页面。
  • webNavigation：核验活动文档、浏览器前进/后退恢复及 iframe 中的 Shift 命中。文档身份仅维护于后台内存，不保存或上传浏览历史，也不持续向后台上报鼠标移动。

五、如何控制与清理

  • 关闭“自动翻译”停止新页面自动启动；当前页一旦开始仍会补翻，需点击取消停止。关闭悬停翻译可停止悬停触发。
  • 离开标签页或最小化窗口会暂停网页新发送；在途请求可能完成，返回后按页面状态继续。取消后主动 Shift 单段仍可用，不恢复整页会话。
  • 取消会清理本页排队任务，并尝试中止仅由本页使用的请求。其他页面仍依赖的共享请求会保留；已经被服务方接收的数据无法通过取消撤回，仍可能被处理或计费。
  • 可在设置页清空凭据、编辑或删除术语规则，在 Chrome 扩展管理页调整网站访问权限，或卸载扩展清理其存储。主动导出的 JSON、下载文件及第三方服务保存的数据需另行管理。
