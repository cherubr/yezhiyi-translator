# 发布检查记录

检查日期：2026-10-19。当前代码版本为 0.9.0，以下为 1.0 发布前准备，不代表已完成商店审核。

## 自动验证覆盖

- 全部 JavaScript 语法、Manifest 文件引用、开发版本一致性。
- Unicode/UTF-8 分块、中文/日文/韩文边界、显式简繁转换。
- 本机密钥迁移、失败保留、同步分流及网络错误。
- 自定义地址解析、拒绝权限不发送请求、后台权限校验。
- 请求去重、语言/服务配置缓存隔离、过期与淘汰、并发控制、冷却及熔断。
- Chromium 的布局、链接事件、表单控件、弹框、动态原文追加与替换、取消恢复、错误显示和重试上限。
- 2500 行构造长页面和 500 条译文记录：单段更新不做全页扫描；耗时只作诊断，不设机器相关的通过门槛。
- 实际加载扩展并访问本地模拟接口，验证后台到内容脚本的完整链路；不调用收费 API。
