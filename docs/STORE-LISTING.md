# Chrome 网上应用店上架材料

当前准备版本：1.0.0。本文是填写草稿，不代表已发布、已审核或真实外部服务已全部验收。

## 商店名称和简介

名称：页知译 · 网页双语翻译

简介：保留网页原文，按段落显示译文，支持多种翻译服务、动态内容补翻及自定义 AI 接口。

## 详细介绍（可复制）

页知译是一款网页双语翻译扩展，帮助你在阅读原文的同时查看译文。

- 双语对照与仅译文两种显示方式。
- 支持整页可见内容、选中文字和悬停翻译。
- 识别普通段落、侧栏、网页弹框及控件旁的说明文字。
- 动态内容按区域补翻；取消后恢复原文并暂停当前页面的后续补翻。
- 支持 Google、MyMemory、百度及 OpenAI 兼容 AI 接口，可连接本机 Ollama。
- 提供 48 种语言选项，源语言默认自动检测，目标语言可跟随浏览器或手动设置。
- API 密钥仅保存在本机，普通偏好可通过 Chrome 同步。

新安装默认关闭自动翻译。翻译文字会发送至你选择的服务；百度及多数 AI 服务需要自行配置账号和密钥，费用和额度由服务方决定。服务可用性受地区、网络、账号和语种影响，不承诺无限免费或所有网站完全兼容。

不支持图片文字、iframe、Shadow DOM、浏览器内置页面及原生系统弹框，不翻译输入框中已填写的内容。MyMemory 对部分短文本无法自动识别源语言，请手动指定。

## 单一用途

根据用户选择的语言和翻译服务，在当前网页中提供双语阅读与文字翻译。

## 权限理由（按后台实际字段拆分填写）

- contextMenus：为网页与选中文字提供翻译入口。
- storage：保存语言和行为偏好；本机保存用户填写的接口凭据。
- tabs：查找并复用扩展设置页标签，向用户正在操作的页面发送翻译控制消息。不用于记录浏览历史。
- 所有网站内容脚本：在用户浏览的网站中识别文字、显示译文及悬浮球，支持动态内容补翻。Chrome 限制的页面无法注入。
- 默认翻译服务域名：后台直接调用用户选择的内置翻译服务，不经开发者服务器转发。
- 可选 HTTPS 域名：用户主动启用或测试自定义 AI 地址时，仅申请该接口地址的访问权限。
- 本机 HTTP 域名：仅用于 localhost 和 127.0.0.1 上的本机模型服务；远程 HTTP 地址被拒绝。

不要把所有网站内容脚本描述成“只在点击后注入”：实际是 document_idle 注入，但新安装默认不自动翻译。

## 隐私字段填写提示

- 不要笼统填写“扩展不访问或不传输任何用户数据”。
- 会访问并向所选服务发送待翻译的网站文字，应按后台当前定义申报网站内容。
- 用户手动选择的文字仍可能包含私人信息；实际支持的数据类型以后台定义和最终行为为准。
- API 凭据保存在本机，调用服务时用于身份验证；普通配置可由 Chrome 同步。按后台关于身份验证信息的定义如实申报。
- 不记录浏览历史、不出售数据、不用于广告、不包含统计代码，不执行远程下载的 JavaScript。
- 页面文字仅用于用户请求的翻译功能。第三方服务的保留、训练规则取决于该服务，不能承诺其从不留存或训练。
- 仔细核对后台的用途与有限使用声明后再勾选，不把本文当作已填写的后台表单。

## 审核测试说明（验收后据实填写）

1. 安装扩展，在普通网页点击扩展图标或悬浮球。
2. 默认自动翻译关闭；先选 Google，源语言选英语、目标选简体中文，用英文公开网页测试。
3. 若审核环境不能访问该服务，请说明实际可用服务及配置步骤，不在公开文档提供任何私人 API 密钥。
4. 可检查设置页语言和显示模式；点击取消应恢复网页。
5. 百度/AI/Ollama 等选项需要自行提供有效服务配置。具体测试账号按审核要求通过审核专用渠道提供。
